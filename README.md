ROS 2 Navigation Using Nav2, SLAM Toolbox, and RTAB-Map
Overview

This project demonstrates autonomous navigation in ROS 2 using the Navigation2 (Nav2) stack integrated with both SLAM Toolbox and RTAB-Map. The system enables a mobile robot to perform mapping, localization, and path planning in indoor
environments.

Features
2D mapping using SLAM Toolbox
3D visual SLAM using RTAB-Map
Autonomous navigation with Nav2
Global and local path planning
Obstacle avoidance
Goal-based navigation through RViz2
Real-time map generation and localization
